# local-road-issue-reporter
A frontend web application to report and track local road problems like potholes, damage, and waterlogging using HTML, CSS, and JavaScript.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 💡 Features
- User can report road issues
- Get location feature
- Upload image
- Clear all problems option
